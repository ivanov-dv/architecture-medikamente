# Защита данных при хранении и передаче

## Классификация и защита

| Данные | Класс | Риск | В чём необходимость защиты | At rest | In transit | In use | Автоконтроль |
|---|---|---|---|---|---|---|---|
| Медкарты, диагнозы, анализы | Специальная категория ПДн | Очень высокий | Врачебная тайна, 323-ФЗ ст. 13; 152-ФЗ ст. 10 | AES-256, KMS | TLS 1.3, mTLS | ABAC: свой приём; маскирование | Аудит доступа, DLP |
| ПДн пациентов, договоры, согласия | ПДн | Высокий | Утечка ПДн, 152-ФЗ ст. 19 | AES-256, токенизация ID | TLS 1.3, OAuth2 | RBAC; маскирование контактов | BigID, теги, контроль выгрузок |
| Платежи и чеки | Платёжные данные | Высокий | Подмена операций, ущерб | AES-256, токенизация карты | TLS 1.3, mTLS | Маскирование номера карты | Контроль целостности, алерты |
| ПДн сотрудников | ПДн | Высокий | Зарплата, паспорт, СНИЛС | AES-256, отдельный HR-домен | TLS 1.3 | RBAC по роли | Аудит, DLP |
| ТМЦ, закупки, поставщики | Коммерческая тайна | Средний | Коммерческий ущерб, 98-ФЗ | Шифрование томов и бэкапов | TLS 1.3 | RBAC | Аудит изменений |
| Журналы аудита | Служебные | Средний | Доказательная база, целостность | Неизменяемое хранилище | TLS 1.3 | Только чтение, роль «безопасность» | SIEM, контроль целостности |

## Реестр средств защиты

| Средство | Тип | Назначение |
|---|---|---|
| Vault / KMS | ПО | Ключи, секреты, ротация |
| BigID | ПО | Обнаружение ПДн, теги, lineage |
| SIEM | ПО | Сбор журналов, алерты |
| DLP | ПО | Блокировка выгрузок ПДн |
| API Gateway | ПО | TLS/mTLS, OAuth2, фильтрация полей |
| BitLocker / LUKS | ПО | Шифрование дисков серверов и ПК |
| HSM | Аппаратное | Хранение мастер-ключей |
| NGFW | Аппаратное | Сегментация сети, периметр |
| Серверы с TPM | Аппаратное | Ключи шифрования дисков |
| Зашифрованные носители бэкапов | Аппаратное | Резервные копии вне офиса |
