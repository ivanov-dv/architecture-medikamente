# Данные, защита и тегирование

## Данные и способы защиты

| Категория | Шифрование | Обфускация | Обезличивание |
|---|---|---|---|
| ПДн пациента | AES-256, TLS | Токенизация ID, маскирование контактов | Псевдонимизация в аналитике |
| Медицинские данные | AES-256, mTLS | Токен пациента для лаборатории | Обезличивание для BI/ML |
| Договоры | Шифрование хранилища | Маскирование паспортных данных | Псевдонимизация |
| Платёжные данные | Шифрование БД, TLS | Токенизация карты | Агрегация |
| ПДн сотрудников | Шифрование БД, TLS | Маскирование счёта | Агрегация |
| Коммерческая информация | Шифрование БД, TLS | — | Агрегация |

## Тегирование

1. BigID сканирует файлы, БД и почту, находит ПДн и медицинские данные.
2. Присваивает теги: `PII`, `PHI`, `PAYMENT`, `EMPLOYEE_PII`, `COMMERCIAL`.
3. Владелец данных подтверждает теги.
4. По тегам применяются политики: шифрование, доступ по ролям, маскирование, удаление.

## Инструменты и меры

- **BigID** — обнаружение, классификация, теги, lineage.
- **API Gateway** — OAuth 2.0, mTLS, проверка принадлежности данных пациенту.
- **RBAC/ABAC** — доступ по роли и принадлежности к приёму.
- **Vault/KMS** — ключи и секреты.
- **TLS 1.3, AES-256** — передача и хранение.
- **Аудит + SIEM** — журнал доступа, оповещения о нетипичных действиях.
